# 社区行为准则 / Code of Conduct

本项目采纳 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) 的核心原则，致力于维护专业、理性、彼此尊重的开源协作环境。

This project follows the core principles of [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) to maintain a respectful, constructive, and harassment-free open-source community.

## 我们的准则 / Our Standards

鼓励有助于推进问题解决与工程质量的行为：

- **聚焦事实与复现**：讨论缺陷、设计与架构取舍时给出可复现步骤、环境信息与客观依据，对事不对人。
- **尊重不同环境与经验水平**：耐心回应新用户与贡献者的问题，建设性地提出代码审查意见并坦诚接受反馈。
- **保护隐私与安全边界**：不在公开 Issue、Pull Request 或日志中张贴他人的个人隐私信息、真实私人语音录音或任何 API 密钥与访问凭据。

Examples of encouraged behavior:

- Focus on technical facts, reproducible steps, and concrete trade-offs rather than personal criticism.
- Offer and accept code review feedback constructively and respectfully.
- Respect user privacy and security boundaries: never post private audio recordings, personal data, or live credentials in public issues or pull requests.

不可接受的行为包括但不限于：人身攻击、侮辱或歧视性言论、骚扰、未经授权公开他人非公开信息，以及持续干扰正常技术讨论的行为。

Unacceptable behavior includes personal attacks, derogatory or discriminatory language, harassment, publishing private information without permission, or disrupting technical discussions.

## 执行与反馈 / Enforcement

如发现违反本准则的行为，请通过仓库维护者联系方式或 GitHub 私密报告渠道反馈。维护者有权编辑、隐藏或关闭不符合本准则的评论、Issue 或 Pull Request，并在必要时限制违规账号的仓库互动权限。安全漏洞请参见 [SECURITY.md](SECURITY.md)。

Instances of unacceptable behavior may be reported privately to the repository maintainers. Maintainers may edit, hide, or close off-topic or abusive comments, issues, and pull requests as appropriate. For security vulnerabilities, please follow [SECURITY.md](SECURITY.md).
