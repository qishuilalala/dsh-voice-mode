# 开发协作推进体系（角色 · 流程 · 门禁）

> 目标：把"全版本兼容"这类跨版本、跨会话、跨智能体的工作，变成可分工、可交接、可审计的协作流程。
> 与 `CLAUDE.md`（本机规则入口，gitignored）的关系：本文件是**仓库内**可提交的协作契约，只写本仓库的流程；通用行为基线仍以全局契约与 CLAUDE.md 为准，不重复。

## 一、角色分工

| 角色 | 职责 | 产出 | 禁令 |
|---|---|---|---|
| **主会话（唯一写者）** | 读证据、写代码、跑验证、落盘 | commit + 实证文档 | 不把未实证的结论写进文档 |
| **只读子代理（取证）** | 并行读源码/日志/registry，结构化输出 | 结论 / 证据[文件:行] / 缺口（限篇幅） | 不写文件；结论只作线索，主会话逐一核对后才采用 |
| **审查者（对抗性）** | 按固定桶输出审查意见 | Blocker / Important / Minor / Open Questions / Verdict | 不直接改代码；无固定格式的评审不接受 |
| **用户（拍板）** | 范围决策、发版批准、key 授权 | 拍板指令 | 不替用户做范围外决策（如升级生产 dsh、回填历史文档） |

## 二、标准推进流程（四阶段）

```
取证 → 实施 → 验证 → 沉淀
```

| 阶段 | 输入 | 动作 | 输出 | 门禁 |
|---|---|---|---|---|
| **取证** | 任务描述 | CodeGraph 优先；只读子代理并行；官方源码/README/registry 实证；**不预设结论** | 证据清单（文件:行 + 实测输出） | 无证据不写代码 |
| **实施** | 证据清单 | 外科手术式改动（只动必须动处，每行可追溯需求）；批量脚本改源码后逐段 diff 复核 | 工作区改动 | `npm run typecheck` 通过 |
| **验证** | 工作区改动 | 按 TEST-SYSTEM.md 四层验证；真流程用隔离环境 + 授权 key；失败先定位到"插件代码 / 测试装置 / 宿主行为"三者之一 | 实证矩阵（版本×维度） | 对抗性复核：逐项证据分级，无"已完成"口头标记 |
| **沉淀** | 实证矩阵 | compat-contract 追加（不改历史行）→ STATE 新 H2 段 → Hindsight Correction/方法论 → 汇报 | 可续跑的恢复点 | 交接文档含：当前状态、唯一下一步、剩余风险、文件白名单、禁令 |

## 三、固定门禁（任何任务通用）

1. **证据链**：结论绑定「输入/时序 → 文件:行 → 后果」；不确定标待核对，不猜。
2. **范围纪律**：用户边界词（只读/诊断优先/一次一个原子）严格执行；顺手优化、无问题重构、风格改造都不做。
3. **Git 纪律**：绝不 `git add -A`；白名单/`--only` 提交；中文专业克制信息；不重置不强推。
4. **发布纪律**：BUILD_TAG 节拍（源码 commit → TAG-only 对齐）；`lib/` 重建只在发版时；npm `latest` 传播需显式验证。
5. **凭据纪律**：明文 key 只进进程 env（`/root/.env` 为真源），不落文档/commit/日志；`DEEPSEEK_API_KEY` 等值永不回显。

## 四、goal 长任务协作（本轮模式固化）

- **goal 是跨轮次容器**：objective 写清目标 + 精确续跑点（已完成 / 下一步1234 / 证据位置）；每轮结束更新，不完成不 close。
- **恢复点必须可直接续跑**：工作区状态 + 唯一下一步 + 剩余风险 + 文件白名单 + 禁令（见 STATE.md 对应 H2 段）。
- **中断恢复**：新一轮先 `get_goal` + `git status` + 读续跑点文档，再动手；不假设上一轮叙述仍然有效。
- **阻塞上报**：同一阻塞条件持续 3 轮以上才标 blocked；难度/不确定性/剩余工作量不是 blocked。

## 五、本轮实例（全版本兼容，可照抄）

- 取证：25 版全集（npm）+ 官方源码（dsh-agent-default-model 范式、dsh-settings README）+ 子包 peerDeps 实证 + 探针脚本（volatile 破坏性、HMR 归因对照）。
- 实施：shim 双路径（Config 扩展 + bridge + mode 双写），中途一次批量正则事故→逐段手工重建。
- 验证：9 版 typecheck 全过 + 24 版真流程 PASS（装饰性数字见 TEST-SYSTEM.md §六）+ 380 单测 exit 0 + 生产健康三指标。
- 沉淀：compat-contract §10/§11 + STATE H2 + Hindsight 两篇 + 本轮汇报。
- 缺口诚实登记：0.0.1-rc.1/rc.2 不可安装（三重证据，不再追）/ 工作区未提交（等拍板）。
