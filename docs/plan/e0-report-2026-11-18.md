## 范围例外声明（2026-11-19 补，两轴审查 Spec #5 提出）

master-plan 与 review-2026-11-18（B4）原定「E0 只许报告、不许改 pin，失配另开修复 PR」。实际执行时把 prefetch 的 revision 修复（commit `dac007b`）随本批一起提交了。**如实记为越界**，理由与边界如下：

- 修复对象是 CLI 工具 `scripts/prefetch.mjs`（离线预取用），**不改运行时行为**——运行时的 revision pin 早已存在（`tts-local.ts`），线上从未破；
- 若不修，prefetch 必然对 3 个文件校验失败，等于让用户跑一个必然失败的工具；
- 该修复是独立 commit（可单独 review/revert），并附带清单一致性守卫测试（`test/prefetch-pins.test.mjs`）。

处置：不回溯拆分 PR（分支尚未合入），但在 PR 说明与 STATE 中显式登记该越界，后续批次恢复「报告与修复分离」口径。
