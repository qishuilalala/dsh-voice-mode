## 1. 第一性原理（成功链与总成本）

最小成功链：开麦 → 保留表达（一字不丢）→ 可编辑草稿 → 按设置发送 → 宿主回复 → 可选朗读 → 可打断并回到明确状态。
总成本 = 等待 + 纠错 + 状态判断 + 故障恢复 + 隐私/费用 + 维护负担。凡不能降低总成本的改动都不做。
