- **现行功能、快捷键与设置说明**：以仓库根 [`README.md`](../../README.md)、[`plugin/dsh-voice-mode/README.md`](../../plugin/dsh-voice-mode/README.md) 及 [`README.en.md`](../../plugin/dsh-voice-mode/README.en.md) 为准。
- **现行开发者上下文与架构决策**：以仓库根 [`CONTEXT.md`](../../CONTEXT.md) 与 [`docs/adr/`](../adr/README.md) 为准。
- **现行兼容范围与路线图**：以 [`docs/compat-contract.md`](../compat-contract.md)、[`docs/plan/roadmap-2026-10.md`](../plan/roadmap-2026-10.md) 与 [`docs/plan/plan-2026-11.md`](../plan/plan-2026-11.md) 为准。
- **当前状态与恢复点**：以 [`docs/rules/STATE.md`](../rules/STATE.md) 为准。
