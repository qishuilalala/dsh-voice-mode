# 开源治理核查记录（2026-10-28）

## 范围与验收口径

核查对象为当前仓库、公开工作流、贡献入口、安全声明与维护者本机发布脚本。按桌面或浏览器内的单用户语音会话评估；不把本轮当作完整渗透测试或跨平台认证。每项完成必须有代码或命令证据。

## Blocker

整体治理尚不能全量验收：真实麦克风/模型、跨平台和全产品端到端未在本轮执行。外部目录是否合并由维护方决定，不纳入可由本仓独自完成的事项。

## Important

1. 辅助模型目录未逐文件固定摘要。主要模型已校验摘要，但辅助目录只检查清单与文件存在；安全声明已收窄，后续需要独立设计清单锁定与更新策略。
2. 分支保护目前仅要求 test，strict=false、enforce_admins=false，无必需评审；安装、审计和扫描不是必需检查。本轮只取证，未更改远端权限策略。
3. 本机发布脚本被 Git 忽略，其修复不会随仓库传播。公开发布入口为 GitHub Release 工作流；本地维护流程不能当作开源贡献者的可复现流程。

## 已修复与验证

- 本机发布脚本：路径显式传参、停止强制覆盖标签、HTTP/API 响应失败中止。Shell 语法与三种响应分支离线检查通过，未调用发布。
- 安全声明：历史命中与当前状态分开，披露宿主对话和 Edge 文本去向，修复包内安全策略链接，说明辅助目录摘要边界。
- 贡献入口：增加贡献指南和英文 PR 模板，要求具体复现、实际验证及未覆盖项。
- 工作流：三个工作流使用仓库现有已验证的 Action SHA；主 CI 显式只读权限并限制任务 30 分钟。全部 YAML 可解析。
- 首页与包文档的静态 passing 徽章已替换为实际 CI 状态；贡献指南已接入首页。
- 本地双 typecheck 与完整 npm test 均正常退出，退出码为 0。
- 文档锚点基线未调整：DRIFT 0/0、无法判定 121/121。变更空白检查通过。
