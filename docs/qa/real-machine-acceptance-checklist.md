### [ ] 8.1 麦克风按钮即状态面板（**L1 核心必过**，PR #16 主特性）
- **前置**：1.1 通过
- **步骤**：
  1. 打开 dsh Web 任意会话，看**发送键旁**的图标按钮
  2. 按 `Ctrl+Shift+V` 进语音模式 → 说话（看按钮电平）
  3. 让 AI 朗读（看按钮电平与颜色）
  4. 设置 → 语音模式 → 关「状态条」→ 再进语音模式说话
- **预期**：
  - 按钮在**发送键旁**（dsh ≥0.1.7 挂 `conversation.input.activity`；更早版本挂 `conversation.input.right`；两处同时注册但**同一时刻只渲染一个**）
  - 聆听=绿色竖条跟麦克风电平；朗读=蓝色竖条跟播放电平；按住=红色；once 等待=转圈；收尾=对勾
  - 关掉状态条后，录音计时显示在**按钮下方**、提示文字显示在按钮旁（不再依赖状态条）
- **失败信号**：按钮整个不见了 / **出现两个 mic 按钮** / 颜色与状态不对应 / 竖条不动 / 关状态条后计时与提示一起消失
- **回退**：检查 `src/mic-gesture.ts` 与 `src/client.tsx` 的 activity/right 双槽位注册分支（activity 被别的注册者遮住时的 1.5s 兜底）
- **时间**：2 分钟

### [ ] 8.2 朗读范围 `readAloud` 三档（**L1 核心必过**，PR #16 主特性）
- **前置**：1.3 通过
- **步骤**：
  1. 设置 → 语音模式 → 「朗读回复」选**语音模式**（默认）→ **不进语音模式**，用输入框打一条消息 → 观察
  2. 同一设置改选**总是** → 再打一条消息（仍不进语音模式）→ 观察
  3. 改选**关闭** → 进语音模式让 AI 朗读 → 观察
- **预期**：
  - 语音模式档：打字消息**不朗读**；语音模式的回复朗读
  - 总是档：打字消息**也朗读**（仅当前可见会话的回复）
  - 关闭档：**都不朗读**（且不报错）
- **失败信号**：档位不生效 / 总是档不朗读打字回复 / 关闭档仍出声
- **回退**：检查 `src/index.ts`（`readAloud: 'voice' | 'always' | 'off'` schema）+ `src/client.tsx` 的 `readAloud` 分支
- **时间**：3 分钟

### [ ] 8.3 同一会话多标签页只在焦点标签页朗读（**L1 核心必过**，PR #16 主特性）
- **前置**：8.2 通过（朗读范围 = 总是）
- **步骤**：
  1. 复制当前标签页（同一会话开两个标签页）
  2. 切到**标签页 A** 让 AI 回复（切到 A 即上报焦点）
  3. 切回**标签页 B**，在 B 打字发一条消息 → 观察
  4. 关掉 A（焦点标签页）→ 在 B 再发一条消息
- **预期**：同一会话多标签页**只有焦点标签页出声**，不叠播；关掉焦点标签页后焦点被清空（该页不再替它朗读）
- **失败信号**：两个标签页同时出声 / 关掉焦点页后仍在朗读 / **切标签页后 `readAloud=always` 突然不再朗读**（= SSE 去重的焦点保持不变量被破坏，见 CHANGELOG `[Unreleased]` 复核新发现 ②）
- **回退**：检查 `src/index.ts` 的 `POST /voice-mode/focus` 路由 + `src/index.ts` 的 `focusedSessionId` / `focusedTabId` 焦点归属
- **时间**：3 分钟

### [ ] 8.4 说完就关 `mode:once`（**L1 核心必过**，PR #16 主特性）
- **前置**：1.3 通过
- **步骤**：
  1. 设置 → 语音模式 → 交互模式选**说完就关**（once）
  2. 说一句话 → 等 AI 回复 → 让回复**朗读完**
  3. 观察是否自动退出语音模式
- **预期**：一句话发出即关麦（**保留语音会话以朗读回复**）；回合结束 + host 朗读队列排空（新 `tts-idle` 事件）+ 本地播完 + 稳定 1.2s 后**自动退出语音模式**；关闭自动发送时说完这一段即退出、文字留在草稿
- **失败信号**：不退出 / 句间空档就提前退出（`tts-idle` 早到）/ 退出前把回复噤声
- **回退**：检查 `src/client.tsx` 的 `beginOnceWait` 调用点与 `exitModeRef.current('manual')` 两处 once 分支 + host 侧 `tts-idle` 广播
- **时间**：2 分钟

### [ ] 8.5 右键快捷设置 + 停止朗读（L2 修复后必过，PR #16）
- **前置**：1.3 通过
- **步骤**：
  1. **鼠标右键**点 mic 按钮 → 观察菜单项
  2. 菜单里改「交互模式」/「朗读范围」/「字幕」/「状态条」/「自动发送」→ 观察是否即时生效
  3. 菜单里按方向键切换、`Esc` 关闭 → 观察焦点是否回到按钮
  4. **按住说话**（不要右键）→ 观察是否仍能按住说话
  5. 不在语音模式但**正在朗读**时，**点** mic 按钮
- **预期**：
  - 仅**鼠标右键与键盘菜单键**开菜单；**触屏长按仍是按住说话**（不被右键菜单劫持）
  - 菜单改动与设置卡片**同一 scope** 读写、即时生效
  - `Esc` 关闭并把焦点还给按钮
  - 正在朗读时点按钮 = **停止朗读**（停当前句 + 清 host 队列 + 本次回复剩余句子不再播，含工具调用后的后续作答；下一次发起回合自动恢复）
- **失败信号**：右键把模式切走 / 长按被菜单劫持 / 停止朗读后又接着播 / `Esc` 后焦点丢失
- **回退**：检查 `src/client.tsx` 的 `onContextMenu` 与 `onPointerDown` 及其 `if (!isPrimaryPress(e.button)) return` 非主键守卫
- **时间**：3 分钟
