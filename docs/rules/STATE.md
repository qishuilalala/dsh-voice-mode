## 当前版本与发布状态

- 最新正式版为 `v0.7.45`（2026-11-23，提交 `9a8899f`）。该版修复 dsh `0.2.3` 线上「首个语音回合必失败」的破坏性变更，并让运行态冒烟适配新宿主的 token 鉴权；上一个正式版为 `v0.7.44`。
- 兼容上界推进到 dsh **`0.2.3-alpha.2`**：现行验证集 10 版、历史全集 28 版；四层实证见[兼容契约 §32](../compat-contract.md)。
- **主干已合入但未发版**：`engines.dsh` 准入承诺 × 验证矩阵一致性门禁（`89a1f71`，纯工具链、不改用户面），随下次发版进包；未发布改动见[变更日志](../../CHANGELOG.md#unreleased)。
- 构建使用 [vendor](../../plugin/dsh-voice-mode/vendor) 内锁定的 `@voice-mode/core@0.1.0` 压缩包，`lib/` 产物与源码分提交。

## 本机运行态与部署边界

- **安装与构建**：正式包用 `dsh plugin --profile web add dsh-voice-mode` 安装，`web` 按实际 profile 替换。源码安装、重建与提交产物见[贡献指南](../../CONTRIBUTING.md#本地开发)。
- **生效方式**：浏览器侧改动刷新页面生效；宿主侧改动需重启宿主进程生效。
- **回滚锚点**：上一正式版本 `v0.7.44`，当前正式版本 `v0.7.45`。

## 后续工作重点

- **真机验收仍是最大缺口**：`v0.7.45` 只有自动化与隔离浏览器冒烟证据；[四项必过清单](../qa/must-verify-manually.md)与真实麦克风启动/退出、`0.2.3` 线上的真实语音往返均待维护者复核，失败即开补丁 PR。
- **L4（真实 LLM 回复→朗读闭环）** 长期未闭环：账户可用性受限，非版本问题，见兼容契约各节口径。
- 按 [11 月实施规划](../plan/plan-2026-11.md) 推进：外放无原生回声消除场景的地板稳定性与 Safari 实机样本采集；按语音段长度评估定稿超时预算。**该规划窗口已于 11-25 关闭并落盘未闭环清单**；下一窗口待维护者决定续期或以新规划替换。
- 持续跟进 `@deepseek-ai/dsh` 上游（每日巡检工作流 + `npm run check:engines` 双保险）；`0.1.3` 线为已登记未验证，若要收编按脚本注释路径补验。
- 观察 `v0.7.45` 线上反馈，尤其是 `0.2.3` 预览宿主上的语音回合与设置写入。
