- **部署形态**：支持 `dsh plugin add dsh-voice-mode` 正式包安装与 `link:` / `file:` 本地包形态；改源码后必须运行构建脚本重建入库产物（漂移门禁与构建标签守卫校验）。
- **生效边界**：客户端改动刷新页面即生效；宿主侧改动需重启宿主进程生效。
