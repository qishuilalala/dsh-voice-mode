## 当前版本与发布状态

- **最新已发布版本：`v0.7.41`**（2026-11-21）：
  1. **快捷键与交互提示完善**：补齐悬停、状态条、设置面板行内说明及按模式独立的首次引导；针对 macOS 自动展示 `⌃ Control`、`⌥ Option + Return` 等本地化键帽提示；将按住说话模式下键盘 `Ctrl` 触发延迟由 `600ms` 收紧至 `220ms`，提升按住收音态在状态条中的显示优先级，并在组合键场景自动丢弃误录片段。
  2. **跨平台兼容性加固**：[tts-vits-worker.ts](../../plugin/dsh-voice-mode/src/tts-vits-worker.ts) 改为仅在初始化 `kokoro` 时按需动态加载 `sherpa-onnx-node`（`loadNativeSherpa`），避免缺少预编译原生插件的平台（如 Windows ARM64、Linux musl）启动子进程即崩溃而连带影响纯 WASM 的 `vits` 引擎；同步 [check-anchors.mjs](../../plugin/dsh-voice-mode/scripts/check-anchors.mjs) 默认检查列表至现行 9 个宿主版本（`0.1.1-rc.2` 至 `0.2.2-rc.5`），并在兼容契约补齐操作系统/架构/浏览器支持矩阵。
  3. **开源文档与仓库治理整理**：清理发布包 README 混入的内部验证手记与失效相对链接，统一中英文文档快捷键表与五类 TTS 数据流声明，归档阶段性计划与审查过程文件至 [docs/archive/](../archive/README.md)，并补齐许可证派生署名同步、社区行为准则与 Issue/PR 模板。
- **上一版本：`v0.7.40`**（2026-11-21）：支持 7 家在线 TTS 预设与逐预设独立密钥、小米 MiMo 语音合成、识别纠错词表可视化编辑、四分段设置面板以及触屏快捷菜单、切页定稿、字幕回看等交互改进。

## 本机运行态与部署边界

- **安装与构建**：支持 `dsh plugin add dsh-voice-mode` 正式包安装及本地目录安装；修改 `src/` 后须执行 `pnpm run build` 更新入库 `lib/` 产物（由 `check-lib-drift` 与发布工作流 `check-build-tag` 校验）。
- **生效方式**：浏览器侧改动刷新页面生效；宿主侧改动需重启宿主进程生效。
- **回滚锚点**：上一稳定版本 `v0.7.40`，当前正式版本 `v0.7.41`。
