## 本机运行态与部署边界

- **安装与构建**：支持 `dsh plugin add dsh-voice-mode` 正式包安装及本地目录安装；修改 `src/` 后须执行 `pnpm run build` 更新入库 `lib/` 产物（由 `check-lib-drift` 与发布工作流 `check-build-tag` 校验）。
- **生效方式**：浏览器侧改动刷新页面生效；宿主侧改动需重启宿主进程生效。
- **回滚锚点**：上一正式版本 `v0.7.43`，当前正式版本 `v0.7.44`。
