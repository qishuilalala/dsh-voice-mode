## 维护纪律

- 已完成任务只在恢复点保留必要摘要及证据入口；历史过程移入档案，不用独立任务段无限接续。
- 档案保留版本、提交与当时验证结论，不把旧待办当作新授权，不保存部署定位和操作命令。
- `archive/` 是历史快照，其中的行号锚点不再维护、不参与现行校验；守卫将带行号引用计入已有的历史时点类别。
- 当前开发语义见[根 CONTEXT](../../CONTEXT.md)，跨文档索引与历史基线见[文档 CONTEXT](../CONTEXT.md)；两者冲突以根文件为准，任务状态以 STATE 为准。
- 工作顺序与验收见[11 月规划](../plan/plan-2026-11.md)，决策依据见[治理审计](../governance/2026-11-12.md)。
